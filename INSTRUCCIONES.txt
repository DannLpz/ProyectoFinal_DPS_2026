==========================================================

Verifica que dentro de la carpeta estén:
   - backend/
   - ProyectoDPS_FrontEnd-main/
   - docker-compose.yml
   - start.ps1
   - INSTRUCCIONES.txt (este archivo)

3. CONFIGURACIÓN INICIAL
==========================================================

El proyecto necesita 2 archivos .env (variables de entorno).
NO vienen en GitHub por seguridad, hay que crearlos manualmente.

----------------------------------------------------------
3.1 OPCIÓN RÁPIDA: Copiar desde .env.example
----------------------------------------------------------
El proyecto incluye archivos .env.example como plantilla.
Puedes copiarlos y renombrarlos con estos comandos:

   Copy-Item backend\.env.example backend\.env
   Copy-Item .env.example .env

Después editas ambos .env y reemplazas los valores con
tus credenciales reales (ver secciones 3.3 y 3.4).

----------------------------------------------------------
3.2 OPCIÓN MANUAL: Crear backend/.env
----------------------------------------------------------
En VS Code, dentro de la carpeta backend/ crea un archivo
llamado .env (sin extensión) y pega EXACTAMENTE esto:

   DATABASE_URL="postgresql://looka_user:looka_password@postgres:5432/looka_db?schema=public"
   JWT_SECRET="looka_super_secret_key_cambiar_en_produccion"
   PORT=3000
   GEMINI_API_KEY=tu_key_de_gemini_aqui
   FORGE_TIER=standard

Guarda con Ctrl + S.

----------------------------------------------------------
3.3 Crear .env en la raíz del proyecto
----------------------------------------------------------
En la raíz (al mismo nivel que docker-compose.yml) crea otro
archivo .env con:

   GEMINI_API_KEY=tu_key_de_gemini_aqui
   FORGE_TIER=standard

Guarda con Ctrl + S.

----------------------------------------------------------
3.4 Obtener tu API Key de Gemini (gratis)
----------------------------------------------------------
1. Ve a: https://aistudio.google.com/apikey
2. Inicia sesión con tu cuenta de Google
3. Clic en "Create API key"
4. Elige "Create API key in new project"
5. Copia la key completa (empieza con "AQ." o "AIza...")
6. Pégala en ambos .env

IMPORTANTE: El tier gratuito tiene un límite diario que puede
variar según la demanda global de Google. Si se agota, la app
usa automáticamente un clasificador local de respaldo, así que
las funciones siguen operativas aunque no haya cuota disponible.

----------------------------------------------------------
3.5 Verificar que .env NO se suba a Git
----------------------------------------------------------
Los archivos .env NUNCA deben subirse al repositorio.
Verifica que el archivo .gitignore (en la raíz) contenga:

   .env
   */.env
   **/.env

Puedes verificar con:

   git check-ignore -v backend/.env
   git check-ignore -v .env

Ambos comandos deben responder mostrando la línea del .gitignore.

Si por accidente subes tu GEMINI_API_KEY, regenérala
inmediatamente en: https://aistudio.google.com/apikey


==========================================================
4. LEVANTAR EL SISTEMA CON DOCKER
==========================================================

----------------------------------------------------------
4.1 Verificar que Docker esté corriendo
----------------------------------------------------------
Abre Docker Desktop desde el menú Inicio. Espera a que el
ícono de la ballena 🐳 diga "Docker Desktop is running".

Verifica desde PowerShell:
   docker ps

Debe responder sin errores (aunque la lista esté vacía).

----------------------------------------------------------
4.2 Habilitar ejecución de scripts (solo primera vez)
----------------------------------------------------------
Abre PowerShell y ejecuta:

   Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Cuando pregunte, escribe: S
Y presiona Enter.

----------------------------------------------------------
4.3 Ejecutar el script de inicio
----------------------------------------------------------
En PowerShell, navega a la raíz del proyecto:

   cd "ruta\completa\al\proyecto"

Y ejecuta:

   .\start.ps1

El script hace AUTOMÁTICAMENTE:
   1. Verifica que Docker esté corriendo
   2. Instala dependencias del frontend (primera vez: ~2 min)
   3. Levanta los 3 contenedores (PostgreSQL, backend, frontend)
   4. Ejecuta el seed (crea usuario demo + 6 muebles)
   5. Arranca Expo y muestra el QR

Al final verás:

   =========================================
      LOOka listo para usar
   =========================================

     Backend:      http://localhost:3000/api/health
     Frontend Web: http://localhost:8083

     Escanea el QR con Expo Go en tu celular.
     Usuario demo: demo / demo123

5. PROBAR LA APP (4 formas)
==========================================================

----------------------------------------------------------
5.1 En el celular (RECOMENDADO)
----------------------------------------------------------
Requisitos:
   - El celular y la PC deben estar en la MISMA red WiFi
   - Tener Expo Go instalado

Pasos:
   1. Abre Expo Go
   2. Toca "Scan QR code"
   3. Escanea el código que aparece en la terminal de Expo
   4. La app se cargará automáticamente

Credenciales de prueba:
   Usuario:  demo
   Password: demo123

----------------------------------------------------------
5.2 En el navegador del PC (versión web)
----------------------------------------------------------
Abre Chrome o Edge y visita:

   http://localhost:8083

Usa las mismas credenciales: demo / demo123

----------------------------------------------------------
5.3 Desde otro dispositivo usando la IP de la PC
----------------------------------------------------------
Útil para mostrar la app en otra PC o tablet.

1. Averigua tu IP local:
   Abre PowerShell y ejecuta: ipconfig
   Busca "Dirección IPv4" (ejemplo: 192.168.1.9)

2. Desde el otro dispositivo abre el navegador:
   http://TU_IP:8083

   Ejemplo: http://192.168.1.9:8083

Nota: el frontend detecta automáticamente la IP del backend,
no hay que configurar nada.

----------------------------------------------------------
5.4 Verificar que todo funciona (checks rápidos)
----------------------------------------------------------
Abre en el navegador del PC:

   http://localhost:3000/api/health
   → Debe mostrar: {"status":"ok","message":"LOOka backend funcionando 🚀"}

   http://localhost:3000/api/furniture/default
   → Debe mostrar un array con 6 muebles predeterminados

   http://localhost:3000/ar/viewer?model=/models/silla.glb&name=Test
   → Debe mostrar la silla 3D girando con un botón de AR


==========================================================
6. COMPARTIR CON UN COMPAÑERO (misma red WiFi)
==========================================================

1. Ambos dispositivos deben estar en la misma red WiFi.

2. El dueño del backend ejecuta en PowerShell:
   ipconfig
   Y busca "Dirección IPv4" (ejemplo: 192.168.1.9).

3. El compañero desde su navegador visita:
   http://192.168.1.9:8083

4. O desde Expo Go toca "Enter URL manually" e ingresa:
   exp://192.168.1.9:8081

Nota: la app detecta la IP del backend automáticamente, por lo
que no hay que configurar nada extra.

IMPORTANTE: Si el compañero está en OTRA red (WiFi distinto o
datos móviles), la conexión NO funcionará porque el backend
corre localmente en tu PC. En ese caso, se necesita exponer
el backend a internet (Ngrok, Railway, etc.).

7. COMANDOS DEL DÍA A DÍA
==========================================================

Arrancar todo:
   cd "ruta\al\proyecto"
   .\start.ps1

Detener todo:
   Ctrl + C   (en la terminal de Expo)
   docker-compose stop

Ver estado de los contenedores:
   docker ps

Ver logs del backend:
   docker logs looka_backend -f

Reiniciar solo el backend:
   docker-compose restart backend

Reiniciar todo:
   docker-compose down
   docker-compose up -d

Actualizar dependencias tras un "git pull":
   cd backend
   npm install
   cd ..\ProyectoDPS_FrontEnd-main
   npm install
   cd ..
   docker-compose build --no-cache
   docker-compose up -d

8. SOLUCIÓN DE PROBLEMAS
==========================================================

[ERROR] "Docker Desktop no está corriendo"
→ Abre Docker Desktop, espera ~1 minuto y vuelve a ejecutar.

[ERROR] "El puerto 3000 ya está en uso"
→ Otro servicio está usando el puerto. Solución:
     docker-compose down
     docker-compose up -d

[ERROR] "La ejecución de scripts está deshabilitada"
→ Ejecuta en PowerShell:
     Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
   Escribe S y Enter.

[ERROR] El celular no conecta con la app
→ Verifica que PC y celular estén en la MISMA red WiFi.
→ Ejecuta PowerShell como Administrador y corre:
     New-NetFirewallRule -DisplayName "LOOka 3000" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
     New-NetFirewallRule -DisplayName "LOOka 8083" -Direction Inbound -LocalPort 8083 -Protocol TCP -Action Allow

[ERROR] "No pudimos conectar con el servidor" en la app
→ Verifica que el backend esté corriendo: docker ps
→ Verifica que en el navegador del PC funcione:
     http://localhost:3000/api/health
   Debe mostrar: {"status":"ok",...}

[ERROR] "Cuota de Gemini agotada" o "429"
→ El tier gratuito tiene un límite diario variable.
→ Espera 24h o usa una API key diferente.
→ La app usa automáticamente un clasificador local de respaldo,
  así que la demo funcionará igual.

[ERROR] "The table public.Listing does not exist"
→ La migración de base de datos no se aplicó. Solución:
     docker exec -it looka_backend npx prisma db push
     docker-compose restart backend

[ERROR] La cámara AR no se activa en iPhone
→ Debe ser iPhone 6s o superior con iOS 12+
→ Abre Safari (NO Chrome, no funciona)
→ Ajustes → Safari → Realidad Aumentada → "Preguntar"
→ Cierra Safari por completo y vuelve a intentar

[ERROR] El QR de Expo no funciona
→ En Expo Go toca "Enter URL manually"
→ Escribe la URL que aparece arriba del QR:
     exp://TU_IP:8081

[ERROR] Los modelos 3D no cargan
→ Verifica que el backend esté corriendo: docker ps
→ Prueba en el navegador:
     http://localhost:3000/models/silla.glb
   Debe descargar el archivo .glb

10. FUNCIONALIDADES DE LA APP
==========================================================

Una vez dentro, podrás:

📱 Login
   Credenciales de prueba: demo / demo123

🛍️ Catálogo
   6 muebles predeterminados con filtros por categoría.
   Cada mueble tiene un botón de corazón para guardarlo en
   favoritos.

🤖 Para ti (IA)
   Describe un mueble en lenguaje natural ("una silla azul")
   y la IA genera un modelo 3D único con Google Gemini + Forge.
   Filtra automáticamente peticiones que no sean muebles
   (ej: "un carro" es rechazado).

❤️ Favoritos
   Guarda muebles del catálogo tocando el corazón.
   Los favoritos persisten durante la sesión.

📷 Ver en mi espacio (AR)
   Proyecta los muebles en tu entorno real con la cámara del
   celular usando AR Quick Look (iOS) o Scene Viewer (Android).

💰 Publicar mueble
   Ponle precio, título y descripción a cualquier mueble del
   catálogo o generado por IA.

🛒 Mi carrito
   Agrega muebles publicados, revisa el total y simula una
   compra.

11. SOPORTE
==========================================================

Si encuentras un error que no puedas resolver:

1. Verifica los logs del backend:
   docker logs looka_backend --tail 50

2. Revisa si los contenedores están arriba:
   docker ps

3. Adjunta una captura del error completo y los logs
   al canal del equipo.
