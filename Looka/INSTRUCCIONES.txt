==========================================================
3. CONFIGURACIÓN INICIAL
==========================================================

El proyecto requiere UN SOLO archivo .env en la raíz.

----------------------------------------------------------
3.1 Copiar desde la plantilla
----------------------------------------------------------
   Copy-Item .env.example .env

----------------------------------------------------------
3.2 Editar el archivo .env
----------------------------------------------------------
Abre .env en VS Code y reemplaza los valores con tus credenciales:

   DATABASE_URL=postgresql://looka_user:looka_password@postgres:5432/looka_db?schema=public
   JWT_SECRET=tu_clave_secreta_aqui
   PORT=3000
   GEMINI_API_KEY=tu_gemini_key
   TRIPO_API_KEY=tu_tripo_key
   FORGE_TIER=draft

----------------------------------------------------------
3.3 Obtener tus API Keys (AMBAS GRATIS)
----------------------------------------------------------

🔵 GEMINI (clasificación de prompts)
   1. Ve a: https://aistudio.google.com/apikey
   2. Inicia sesión con Google
   3. Clic en "Create API key" → "Create API key in new project"
   4. Copia la key (empieza con "AQ." o "AIza...")

🟢 TRIPO3D (generación de modelos 3D)
   1. Ve a: https://platform.tripo3d.ai/
   2. Crea cuenta gratis
   3. Ve a API Keys y crea una nueva
   4. Copia la key (empieza con "tsk_")
   5. Al registrarte obtienes ~300 créditos gratis
      (suficiente para ~10-15 modelos)

----------------------------------------------------------
3.4 Verificar que .env NO se suba a Git
----------------------------------------------------------
   git check-ignore -v .env
   # Debe responder mostrando la línea del .gitignore


==========================================================
4. LEVANTAR EL SISTEMA CON DOCKER
==========================================================

----------------------------------------------------------
4.1 Docker corriendo
----------------------------------------------------------
Abre Docker Desktop. Espera a que diga "Docker Desktop is running".

----------------------------------------------------------
4.2 Habilitar ejecución de scripts (solo primera vez)
----------------------------------------------------------
   Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
   # Presiona S cuando pregunte

----------------------------------------------------------
4.3 Arrancar todo
----------------------------------------------------------
   .\start.ps1

El script hace AUTOMÁTICAMENTE:
   1. Verifica Docker
   2. Instala dependencias del frontend (~2 min primera vez)
   3. Levanta contenedores
   4. Ejecuta migraciones y seed
   5. Arranca Expo y muestra el QR

Al final verás:
   =========================================
      LOOka listo
   =========================================
     Backend:  http://localhost:3000/api/health
     Frontend: http://localhost:8083
     Login:    demo / demo123

7. SOLUCIÓN DE PROBLEMAS
==========================================================

[ERROR] "Docker Desktop no está corriendo"
→ Ábrelo y espera 1 minuto.

[ERROR] "El puerto 3000 ya está en uso"
→ docker-compose down && docker-compose up -d

[ERROR] "La ejecución de scripts está deshabilitada"
→ Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

[ERROR] El celular no conecta
→ Ambos en la misma WiFi.
→ Como Admin:
     New-NetFirewallRule -DisplayName "LOOka 3000" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
     New-NetFirewallRule -DisplayName "LOOka 8083" -Direction Inbound -LocalPort 8083 -Protocol TCP -Action Allow

[ERROR] "No pudimos conectar con el servidor"
→ Verifica: docker ps
→ Abre: http://localhost:3000/api/health

[ERROR] "TRIPO_API_KEY no configurada"
→ Verifica que la key empiece con "tsk_"
→ Verifica que esté en .env en la raíz
→ docker-compose restart backend

[ERROR] "Sin créditos" en Tripo
→ Se agotaron los créditos gratis (~300).
→ Espera o crea una cuenta nueva.

[ERROR] La cámara AR no se activa en iPhone
→ Requiere iPhone 6s+ con iOS 12+
→ Abre Safari (NO Chrome)
→ Ajustes → Safari → Realidad Aumentada → "Preguntar"

[ERROR] El modelo no carga (queda en "Cargando...")
→ Verifica que el .glb esté en backend/public/models:
     ls backend\public\models
→ Prueba la URL en el navegador:
     http://localhost:3000/models/tripo_xxx.glb

9. ARQUITECTURA DE IA
==========================================================

Pipeline de generación:

   Usuario escribe "una mesa semicircular de madera"
              ↓
   [1. Gemini - Cascada de 5 modelos]
       Prueba: gemini-3.6-flash
       Si falla → gemini-3.5-flash
       Si falla → gemini-3.7-flash
       ... hasta encontrar uno disponible
       ↓
   Retorna: { isFurniture: true, category: "mesa",
              enhancedPrompt: "a 3D model of a modern semicircular wooden table" }
              ↓
   [2. Tripo3D - Generación 3D]
       Crea tarea → Polling cada 3s → 100% success
       ↓
   Descarga el .glb localmente en /models/tripo_xxx.glb
              ↓
   [3. Fallback local]
       Si Tripo falla → usa modelo predeterminado de la misma categoría
              ↓
   Guarda en BD y muestra en la app

Tiempos aproximados:
   - Gemini: 1-3 segundos
   - Tripo3D: 60-150 segundos
   - Total: 1.5 a 2.5 minutos
